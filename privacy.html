Privacy Policy

Work Console · last updated 27 October 2026

Who uses it

Work Console is a personal tool used only by its owner, on the owner's own computer. It is not offered to other people.

What data it accesses

  • Gmail: reads messages and threads of the owner's Google account (read-only access), and sends a message only after the owner confirms that exact message.
  • Google Calendar: reads events (read-only access).

How the data is used

The data is used only to show the owner their own mail and calendar in Work Console, to search them when the owner asks, and to prepare replies for the owner's review. It is not used for advertising, profiling or any other purpose.

Where the data is kept

Data received from Google is processed and stored only on the owner's computer, in a local database. The OAuth tokens are stored locally as well. No data is sent to the developer or to any server operated by Work Console, because there is none.

Sharing

Google user data is not sold, transferred or shared with third parties. When the owner asks an AI assistant on their own computer to work with a message, the content is processed only to perform that request for the owner.

Google API Services User Data Policy

Work Console's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local database and token files on the owner's computer removes all stored data.
